# Telegram Story Bot

Yeh ek Telegram bot hai jo aapke input se kahani generate karta hai.

## Setup

1. Python install hona chahiye (3.10+ recommended).
2. Telegram pe @BotFather se bot create karke token lein.
3. `requirements.txt` install karein:
   ```
   pip install -r requirements.txt
   ```
4. `bot.py` mein `BOT_TOKEN` ke jagah apna token daalein.
5. Run karein:
   ```
   python bot.py
   ```

## Deployment

Koyub ya kisi bhi server pe deploy karne ke liye:
- Code push karein.
- Bot Token secure env variable ya script mein paste karein.
